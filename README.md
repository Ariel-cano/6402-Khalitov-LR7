# ЛР7 — анализ каталога землетрясений USGS

Итоговый мини-проект по дисциплине «Инструментальные средства анализа данных».

## Данные

Significant Earthquakes, 1965–2016, US Geological Survey.

Источник: https://www.kaggle.com/datasets/usgs/earthquake-database

Исходный файл содержит 23 412 записей и 21 столбец. Для исследования будут отобраны события типа Earthquake с магнитудой от 5,5. Лицензия набора CC0.

## Вопросы исследования

1. Как менялось число зарегистрированных в каталоге землетрясений по годам?
2. Как распределены магнитуды и как они связаны с глубиной?

## Структура

- data/ — исходные данные под контролем DVC.
- notebooks/analysis.ipynb — загрузка, очистка, анализ, графики и выводы.
- requirements.txt — зависимости Python.

Хранилище DVC размещено в DVCStorage/lab7 внутри проекта. В ноутбуке выполнены загрузка, первичный обзор и очистка. Анализ, графики и выводы добавляются на следующих этапах.

## Версионирование данных

Git хранит код и небольшие текстовые файлы проекта, а DVC отслеживает версии исходного CSV. В Git включён файл data/raw_dataset.csv.dvc с контрольной суммой, размером и путём к CSV. Сам CSV и его копии в кеше и хранилище исключены из Git, чтобы изменения данных не увеличивали историю репозитория.

Хранилище localstore находится в DVCStorage/lab7. Путь сохранён относительно конфигурации DVC, а папка DVCStorage/ исключена через .gitignore и .dvcignore.

После добавления или изменения данных выполняется dvc push. Эта команда сохраняет версию CSV в хранилище localstore. Команда git push отправляет код и .dvc-файлы в GitHub.

При переносе проекта на другой компьютер нужно скопировать DVCStorage вместе с проектом либо указать доступное хранилище. Для восстановления CSV выполните из корня проекта:

    python -m dvc pull

Команды Python нужно выполнять в окружении data_tools_lab, в котором установлены зависимости из requirements.txt.

## Подготовка данных

Даты двух форматов приведены к единому типу, проверены пропуски и дубликаты. Исключены 180 событий других типов; для анализа осталось 23 232 землетрясения с магнитудой от 5,5. Пропуски вспомогательных полей сохранены: эти поля не используются в исследовании.
